Sentence Functions — Reference ▾
Topic Sentence

Introduces the paragraph's main idea. States the topic and a controlling idea. Usually the first sentence.

Supporting Idea

Introduces one reason, benefit, challenge, or point that develops the topic sentence. Does not include evidence yet.

Detail

Provides specific evidence for the supporting idea above it: a fact, statistic, example, or explanation.

Conclusion

Closes the paragraph by restating the main idea in new words and signaling the end of the argument.
